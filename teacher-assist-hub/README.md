# Teacher Assist QR Link Hub

Static link hub for the Teacher Assist standee/poster QR code.

## Vercel Deployment

When importing this repository into Vercel, set:

```text
Root Directory: teacher-assist-hub
Framework Preset: Other
Build Command: none
Output Directory: none
```

The site entry point is `index.html`.
